# v0.5.0 SelfLearning 运行职责接管

通过social能力声明接入Chat Dynamics的原生社交角色；同一当前注册表即时解析，停用旧SelfLearning后由群间学习承接get_social_context/get_social_snapshot/observe_events。接收事件保存持久回执并去重，原始采集和学习仍走已核对的原生消息及回合反馈，不把Bot输出重复当真人样例。

保留query_affection只读查询工具，以及非Chat Dynamics普通请求的社交上下文注入。私聊只读继承明确授权群来源、同平台同角色、当前成员的资料，不合并跨群好感，也不从私聊写入群状态。受限投影和内部模型请求不注入。

历史迁移：已确认黑话、未被新系统改动的历史好感刷新到最终快照；新系统已应用或回滚过的好感/黑话保持原值。表达、旧审查、成员资料、参考对话、旧目标与旧心情进入历史资料页，保留来源及原状态。旧库中缺少成员来源校验的样例不自动注入。全部旧数据库保留一致性备份，原插件和原数据不删除。

心情和持续生活由群间世界负责，长期记忆继续由群间记忆负责。保留Bot固定性格及好感度自动生效规则。未复制旧SelfLearning独立Web服务、Hub API、旧管理命令、人格演化和未在当前聊天链路使用的扩展后端。
