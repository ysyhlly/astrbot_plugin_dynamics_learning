# v0.12 学习工作台

## 回复材料预览

选择已启用群，填写成员账号和本轮输入。预览调用群间学习实际材料构造，再调用 Chat Dynamics 的公共 `preview_learning_material` 接口；该接口与生产回复复用成员边界过滤函数。不会调用回复模型或发送消息。

主区域展示过滤后可提供的学习材料；展开候选列表可查看角色变化、过期、撤回、相关性、预算和成员边界导致的排除原因。依赖真实群运行记录中的 Bot 身份与已记录角色快照；身份不足时显示不可确认，不伪造最终材料。它不模拟发言时机，也不等于模型已经采用内容；真实回复仍重新验证角色、版本和边界。

v0.12.1 会只读核对当前宿主人格和群间世界角色，与正式回复共用数据契约验证；无法确认当前身份、角色已变或读取期间版本改变时，显示不可用而不是继续使用旧快照。角色读取不会触发媒体档案更新。预览是当前时点的学习材料快照，不承诺未来回合中的所有材料与之固定不变。

## 失效治理与人工保留

「调整审查」增加失效治理、人工保留视图及原因筛选。查询覆盖全部已启用群的待审内容后分页。选择一个群后，可以跨成员、跨页选择，每批最多 100 项。

归档只接受角色变化、过期、版本变化、基线变化或规则不兼容的提案，保留原始证据与审查历史，不改变已生效学习项。提交时重新校验版本及失效原因，任一项变化则整批不执行。

批量任务建立提案级归属。暂停、取消和失败的未完成项不再被自动成员审查接手。暂停任务可以恢复；要交回自动审查，先取消原批次，再在人工保留视图核对并释放。释放会更新提案版本，旧批次不能重放旧版本。部署不会替管理员自动归档或释放条目。

## 资料版本中心

按群、类别、状态、内容或账号查询本插件全部提案，包括拒绝、回滚和归档记录。详情展示当前值、所选提案、原始证据、审查意见、同一学习项的版本、最近 100 条审计和最近 20 条使用回执。同项版本一次展示最近 50 条，完整记录仍保存在数据库并可从版本列表检索。

回滚须确认，且只允许当前版本对应的提案；如果有后续版本或策略变更，则拒绝覆盖。历史导入条目可从已学内容打开，只读展示；原 SelfLearning 档案仍在历史资料。

v0.12.1 将回滚确认戳也放到事务内复核。客户端中断不丢弃已进入提交的操作；提交后立即移除旧缓存，再刷新恢复值。刷新暂时失败时会明确提示“回滚已提交”，后续维护重试，期间不继续提供撤回的旧值。归档保留原话证据、审查记录和待替换前值，不改变当前生效条目。

使用回执记录已到达最终 provider 参数的资料 ID 和版本，新增覆盖黑话、关系等非成员画像类别；不保存提示词，不把回执当成采用或效果证明。

## 兼容与存储

- 需要配套 Chat Dynamics 公共预览接口；发布包附该接口及共用过滤函数的源文件差异。
- SQLite schema 7 增加索引、review_claims 与 reply_usage_refs，不删除原记录。待审查询需要 SQLite 3.35+，部署环境已验证。
- 待审分类在独立只读 WAL 连接中执行，连接内临时表复用分类结果，只为返回页构造 Python 摘要。
- 各管理入口仍需 Dashboard 管理员身份；学习与审查模型、固定人格、成员/群边界和好感度规则不变。
