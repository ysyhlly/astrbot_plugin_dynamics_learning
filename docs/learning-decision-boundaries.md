# 学习的决策边界

规则、角色意愿、发送门禁和最终执行是四个不同问题。`participation.should_reply` 可能已经包含后续阶段，不能替代规则标签。

## 监督资格

- `expected_rule_reply` 是独立的布尔规则标注；不会替换最终 `expected_reply`。只有明确标注规则阶段时，人设模式记录才参与回复准入阈值回放。
- 旧 `expected_reply` 在明确的 `legacy` 模式且没有门禁、生成、发送失败等后续未发送证据时，继续沿用历史的准入标注约定。
- 人设模式、未知模式，以及后续阶段未发送记录保留作诊断样本，但标记 `reply_supervision.eligible=false`，不计入准入指标、参数评测和阈值错误归因。角色合理沉默不能训练成规则错误。
- 历史存储行仍可读取；有 `ctx_mode_persona` 或非准入未发送证据的旧行同样排除。缺失阶段的旧数据无法还原，只能保留历史兼容约定，不代表已验证角色行为。

样本在关闭原始轨迹存储时也保留 `reply_supervision`、`decision_scope` 和受限的 `decision_stages`。只保存宿主实际提供的有限字段；不猜测人设、关系或角色状态。宿主 `review_context.decision_mode` 优先于路由模式；角色指纹仅作会话内来源证明，不当作跨会话行为版本。

## 策略适用范围

发布内容增加 `applicability`：参数只作用于规则阶段，`persona_behavior_validated=false`。兼容性记录观测到的决策模式及排除的回复样本数。没有行为版本和参与偏好契约时对应值为空，不宣称已验证任何角色风格。

这不是新增角色学习系统；通用发言对象标签仍可评估规则，人设意愿、表达质量和长期关系不能从回复率推断。已有策略不会因新增声明获得角色验证证据，宿主旧消费者也不会自动执行新增范围字段。
