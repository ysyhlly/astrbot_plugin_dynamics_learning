# v0.4.0 三层成员学习

原话样例：原生群消息与 Chat Dynamics 回合逐条核对后，提取同群、同角色、不同成员的上下文—原话对。明确回复优先，相邻仅是候选关联；最大间隔五分钟，命令、超长消息等不能充当样例，并保留时间线边界。按独立消息计数，候选排序采用15天半衰期，不以Bot回复为训练原话。已批准样例仅在当前成员、当前场景存在词面关联时注入，最多2条；不相关样例仍可通过当前群 profile 工具查询。

习惯统计：去重计算单条消息长度、≤12字短句、多行、标点、近似表情、90秒内连续补充比例。预览使用当前窗口最近600条已绑定群消息中的成员样本（最多100条），提案保存最近最多60条证据，至少10条才提案。每批至多2条新样例和1条统计提案，统计已有待审提案不重复排队，更新须至少5条新证据。窗口不足不会伪造规律，统计不是打字速度或心理判断。

喜恶摘要：LLM提案必须包含对象、喜欢/反感/边界、适用条件、原话及来源ID。程序核对原话确实存在，LLM和人工审查是否属于本人认真自述。同对象同条件采用同一版本键，批准更新保留前版本并支持回滚；近义词归并仍由审查处理。

三层资料都按完整会话、角色和成员隔离。采集数据与候选仅用于管理预览和分析；回复及工具只返回已批准且未过期内容。默认LLM初审＋人工确认。旧的已审查摘要保留，新增字段不改变角色卡或重新开启人格演化。

只从升级后的原生消息采集精确统计，不把旧合并回调猜成单条消息。数据使用现有retention_days清理，删除会话同时清除三层源数据；提案内证据保留用于审查。学习关闭或群移出生效列表后不采集也不注入。
