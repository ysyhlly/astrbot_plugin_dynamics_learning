# v0.8.0 运行控制台与轻量接口

默认首页改为运行总览：区分采集队列、待分析回合、模型排队，显示24小时生效与模型投影数量、分析/审查耗时、错误、最早重试时间和后续调用成功记录。启动即恢复符合条件的积压；保留原有模型并发和审查策略。

总览只返回摘要，证据、完整审查与应用观察展开后加载；已学条目按有效/过期/撤回筛选并分页。按昵称/账号查找成员，重名时选择具体账号，再查看该成员三层资料。成员统计按本人窗口查询，避免冷门成员被全群最近消息挤掉。

图谱使用缓存快照，只返回20/40/60个可见节点及代表连线，完整成员查找和关系详情按需读取；好感与黑话分页。缓存初次构建或更新时明确显示状态，不伪装实时。全群统计、关系评分与学习数据没有按显示数量裁剪。后台刷新按群合并并限制计算并发，消息写入不等待重算。

新资料使用页记录经过边界过滤、实际出现于provider参数中的资料ID/版本、过往引用、对话锚点与节奏。不保存提示词/原话，不把送入模型说成模型采纳或发送成功。只记录启用群；私聊继续遵守既有只读隔离。未提供的待审、过期或无关资料不伪造使用记录；候选被过滤时记录过滤/身份检查原因。追踪从升级后开始，不补造历史数据。

新增状态/类别/成员索引和有界诊断表，沿用保留周期及会话删除。成员资料仍由LLM通过后自动生效，好感度仍直接生效，原性格与其他配置保持不变。
