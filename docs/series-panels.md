# 互通插件状态与面板跳转

群间学习、Chat Dynamics、群间世界、群间记忆的主面板均提供同一套互通入口。主入口可直接跳转，当前面板不可重复点击；辅助状态显示成员边界与旧 SelfLearning。

状态区分安装、加载、宿主启用与运行接入。公开能力声明 ready=true 才显示已就绪；未声明就绪的插件只显示已启用。未接入的插件仍可打开其已启用面板以配置，停用或缺少页面的插件不提供无效跳转。

每 30 秒在可见页面更新一次，也可以手动刷新。读取失败不伪装为未安装；重复实例或能力查询异常会显示异常状态。接口仅限 Dashboard 管理员，不暴露配置、密钥或提示词。

跨插件跳转通过 AstrBot 导航桥接执行：先验证目标插件启用和目标 View 存在，再切换宿主原生路由，重新建立目标页面的 API 上下文与签名资源地址。不复用源页面 token，不放宽 iframe sandbox。

本版本为宿主补充 navigateToPlugin 桥接（SDK、PluginViewPage 源文件及对应运行资源）。部署后请整页刷新 AstrBot，面板内的数据刷新不重新加载宿主代码。宿主升级可能覆盖该适配；若导航方法不可用，会提示从侧栏打开，不采用不安全的顶层导航绕过。
